# SmartRF-ESP32 硬件规格文档

## 1. 开发板规格

### 1.1 开发板信息

| 项目 | 规格 |
|------|------|
| **开发板型号** | Yuzuki ESP32 SOLO (YuzukiESP32 Rev 1.0) |
| **核心芯片** | ESP32-S0WD (单核，WiFi/BT) |
| **Flash** | 4MB (内置) |
| **USB 转串口** | CH340C (USB Type-C) |
| **电源管理** | USB 5V → AMS1117-3.3 |
| **工作电压** | 3.3V |

### 1.2 板载资源

**LED**:
- 蓝色 LED (LED2)
- 连接：**GPIO 2**
- 逻辑：高电平点亮

**按键**:
- **RESET (EN)**: 复位按键
- **BOOT (IO0)**: 下载模式按键 (GPIO 0)

**自动下载电路**:
- 支持 ESP32 自动下载
- DTR/RTS 控制

### 1.3 ESP32-SOLO1 核心规格

| 参数 | 规格 |
|------|------|
| **CPU** | ESP32-S0WD 单核 Xtensa |
| **频率** | 80/160/240MHz (默认 160MHz) |
| **RAM** | 320KB+ SRAM |
| **WiFi** | 802.11 b/g/n (2.4GHz) |
| **Bluetooth** | v4.2 BR/EDR and BLE |
| **GPIO** | 34 个可用引脚 |
| **外设** | SPI, I2C, I2S, UART, ADC, DAC |

## 2. CC1101 无线模块

### 2.1 模块信息

| 项目 | 规格 |
|------|------|
| **模块型号** | HL-RF433A16-B V2.1 |
| **工作频率** | 433MHz (ISM 频段) |
| **接口类型** | SPI (4 线) + GDO0/GDO2 |
| **工作电压** | **3.3V** (严禁 5V) |
| **支持协议** | ASK/OOK, FSK, GFSK, MSK |

### 2.2 频率范围

CC1101 支持多个频段：
- **300-348 MHz**
- **387-464 MHz** (包含 433MHz)
- **779-928 MHz**

### 2.3 重要警告

⚠️ **供电警告**:
- CC1101 **必须接 3.3V**
- **严禁接 5V**，否则会立即烧毁模块
- ESP32 的 3V3 引脚可提供足够电流

## 3. 引脚连接

### 3.1 推荐接线表

使用 ESP32 标准 **VSPI** 接口：

| CC1101 引脚 | 功能 | ESP32 GPIO | 备注 |
|------------|------|-----------|------|
| **1 VCC** | Power (3.3V) | **3V3** | ⚠️ 严禁 5V |
| **2 GND** | Ground | **GND** | 共地 |
| **3 MOSI** | SPI Data In | **GPIO 23** | VSPI MOSI |
| **4 SCLK** | SPI Clock | **GPIO 18** | VSPI SCLK |
| **5 MISO** | SPI Data Out | **GPIO 19** | VSPI MISO |
| **6 GDO2** | Interrupt/Status | **GPIO 22** | 接收中断 (推荐) |
| **7 GDO0** | Interrupt/Status | **GPIO 4** | 数据包中断 (必须) |
| **8 CSN** | SPI Chip Select | **GPIO 5** | VSPI CS0 |

### 3.2 代码引脚定义

```cpp
// CC1101 引脚定义 (ESP32 VSPI)
#define CC1101_MOSI     23      // SPI MOSI
#define CC1101_MISO     19      // SPI MISO
#define CC1101_SCK      18      // SPI Clock
#define CC1101_CS       5       // Chip Select
#define CC1101_GDO0     4       // Data Packet Interrupt
#define CC1101_GDO2     22      // Receive Interrupt (可选)
```

### 3.3 引脚选择理由

**VSPI 选择**:
- GPIO 23, 18, 19, 5 是 ESP32 的硬件 VSPI 引脚
- 性能最优，速度最快
- 不与内部 Flash 冲突

**GDO0 选择 GPIO 4**:
- 与 ESP8266 版本保持一致
- 普通 GPIO，无特殊功能冲突

**GDO2 选择 GPIO 22**:
- 避免使用 GPIO 2 (板载 LED)
- LED 状态可能干扰 RF 接收
- GPIO 22 是普通 GPIO，无冲突

### 3.4 禁止使用的引脚

⚠️ **GPIO 6-11**: 
- 连接内部 Flash (SDIO)
- **绝对不可用于外设**
- 会导致程序无法启动

⚠️ **GPIO 2**:
- 连接板载 LED
- 如果用作 GDO2，LED 会闪烁干扰
- 建议避开

## 4. 引脚对比表

### 4.1 ESP8266 vs ESP32

| 功能 | ESP8266 GPIO | ESP32 GPIO | 变化说明 |
|------|--------------|------------|----------|
| **SPI MOSI** | GPIO 13 (HMOSI) | GPIO 23 | VSPI MOSI |
| **SPI MISO** | GPIO 12 (HMISO) | GPIO 19 | VSPI MISO |
| **SPI SCK** | GPIO 14 (HCLK) | GPIO 18 | VSPI SCLK |
| **SPI CS** | GPIO 15 (D8) | GPIO 5 | VSPI CS0 |
| **GDO0** | GPIO 4 (D2) | GPIO 4 | 保持不变 ✅ |
| **GDO2** | GPIO 4 (D2) | GPIO 22 | 改到 22 ⚠️ |

### 4.2 移植注意事项

**需要修改的代码**:
```cpp
// ESP8266 原定义
#define CC1101_SCK_PIN      14
#define CC1101_MISO_PIN     12
#define CC1101_MOSI_PIN     13
#define CC1101_CS_PIN       15
#define CC1101_GDO0_PIN     4
#define CC1101_GDO2_PIN     4  // 与 GDO0 共用

// ESP32 新定义
#define CC1101_SCK_PIN      18
#define CC1101_MISO_PIN     19
#define CC1101_MOSI_PIN     23
#define CC1101_CS_PIN       5
#define CC1101_GDO0_PIN     4
#define CC1101_GDO2_PIN     22  // 独立引脚
```

## 5. 电源规格

### 5.1 供电要求

| 设备 | 电压 | 电流 (典型) | 电流 (最大) |
|------|------|------------|------------|
| **ESP32-SOLO** | 3.3V | ~80mA | ~500mA (发射时) |
| **CC1101** | 3.3V | ~15mA | ~35mA (发射时) |
| **总计** | 3.3V | ~95mA | ~535mA |

### 5.2 电源路径

```
USB 5V
  ↓
CH340C (USB 转串口)
  ↓
AMS1117-3.3 (LDO 稳压器)
  ↓
3.3V 系统电源
  ├─ ESP32-SOLO
  └─ CC1101 模块
```

### 5.3 电源注意事项

1. **USB 供电能力**:
   - USB 2.0 最大 500mA
   - 建议使用 1A 以上电源适配器
   - 峰值电流可能达到 535mA

2. **去耦电容**:
   - CC1101 VCC 就近接 100nF 电容
   - ESP32 VCC 就近接 10uF 电容

3. **地线连接**:
   - ESP32 和 CC1101 必须共地
   - 使用粗短的地线
